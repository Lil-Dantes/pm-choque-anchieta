# PM Anchieta CHOQUE V2

Deploy: Render + Supabase.

Variáveis do Render: ADMIN_PASSWORD, SUPABASE_URL, SUPABASE_SECRET_KEY.

No Supabase, execute `supabase/schema.sql` no SQL Editor.

Build: `npm install` | Start: `npm start`.

A SECRET KEY do Supabase é somente para o backend; nunca coloque no navegador ou GitHub.
